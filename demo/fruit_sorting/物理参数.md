# 通用物理参数与依据

这是按公开规格与常见干燥水果尺寸配置的仿真基准，不是对某批实物的辨识结果。默认干燥成熟水果、软橡胶指垫、塑料框。

| 对象 | 配置 | 依据与适用范围 |
|---|---|---|
| 香蕉 | 120 g，约 140 mm 长 | 小香蕉的通用示例取值；文献报道不同品种长度约 105–143 mm。质量需按实际水果称量替换 |
| 苹果 | 100 g，62×62×60 mm | 小苹果通用示例；按椭球计算密度约 828 kg/m³，质量与几何一致 |
| 葡萄 | 小串总重 100 g，7 个约 30 mm 的大果粒 | 按果粒体积量级估计；不是一整串大葡萄 |
| 水果–台面/塑料框 | 香蕉 μ=0.35、苹果 μ=0.30、葡萄 μ=0.25 | 工程估计，温湿度、表皮、成熟度会改变实际摩擦 |
| 水果–软指垫 | μ=0.60 | 采用保守的通用等效值。苹果 TPU 研究的静/动摩擦约 0.88/0.80，葡萄软夹持研究采用 0.60；本例不声称各种水果摩擦完全相同 |
| 2FG7 | 1.10 kg；单侧等效驱动力上限 20 N；总行程速度 16 mm/s | 当前厂商资料：质量 1.1 kg，力范围 20–140 N，速度 16–450 mm/s。使用最低设置；固定肌腱对每根手指产生同样的广义力，不能误除以二 |
| 相机与支架 | 120 g | 通用小相机＋支架估计，真实加入腕部惯量 |
| Panda | 保留模型库各连杆质量、质心、完整惯量 | 模型库来源于公开 Franka 描述；没有为了提高抓取成功率改变机械臂质量 |
| Panda 力矩 | 关节 1–4：87 N·m；5–7：12 N·m | 厂商 FER/Panda 控制接口限制，由模型执行器实际限幅 |
| Panda 速度 | 关节 1–4：2.175 rad/s；5–7：2.61 rad/s | 厂商限制；运行中监测，超过后停止并报告 |

## 模型修正

- 原来统一为 2.0 的水果滑动摩擦，降为上表的分材质数值。MuJoCo 同优先级接触取双方摩擦分量最大值，因此台面/框设为 0.20，指垫设为 0.60；测试检查的是接触中的实际摩擦。
- 苹果采用明确的椭球惯量。香蕉使用五段曲面碰撞和独立惯量，保留弯曲形状。葡萄使用果粒外包凸壳表示刚性小串，避免把果粒间隙当成可以无限穿过的空间。
- 夹爪总质量按资料保留 1.10 kg，质心和惯量从夹爪实体网格与零件质量重新计算；不是原来的所有零件质心均置零。相机/支架单独贡献 0.12 kg。
- 接触使用耗散的软约束（solref 8–12 ms、阻尼比 1）。这是 MuJoCo 的数值接触近似，不能当作水果实测杨氏模量。
- 使用五次平滑插值，起止速度、加速度连续，放置时降低高度；搬运中持续检查双侧接触，滑脱或超速会报错。
- 香蕉在框内横向分两列摆放，避免变长后的两个香蕉沿同一方向互相挤压。

## 如何修改

编辑同目录 physics.json，然后在项目根目录运行：

~~~bash
python -m demo.fruit_sorting.generate_assets
~~~

重新生成会覆盖水果资产与 world.yaml、scene.yaml，不生成标定场景。质量、指垫摩擦、表面摩擦、相机载荷和夹爪力上限会写入 MJCF。水果尺寸修改需同时调整生成器和定位高度先验。

当前仍是刚体＋软接触近似，不模拟果肉压伤、表皮破裂、葡萄果梗断裂。2FG7 的最低夹持力也不代表对成熟葡萄无损。要验证实物无损抓取，需要测量指垫接触压力与果实损伤；若低力要求超出 2FG7 能力，应选合适的软夹爪。
