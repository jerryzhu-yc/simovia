# 机械臂视觉水果分拣

Franka Panda + OnRobot 2FG7 + 腕部 RGB 相机；香蕉、苹果、葡萄各 2 个，三个框。水果场景已移除标定板，直接加载独立标定 demo 生成的结果。

## 看实时识别画面

1. 重启 Simovia，打开“文件 → 水果视觉分拣 Demo…”，或用“打开世界”加载仓库内 demo/fruit_sorting/scene.yaml。
2. 在代码页选择 arm，点击“保存并运行”或按 F5。
3. 右侧“遥操作 / 实时画面”会自动展开。相机为 arm/wrist_rgb，关闭“深度图”。画面显示识别框、BANANA/APPLE/GRAPE 类别与 tick，约按仿真时间 10 Hz 更新。
4. 点击“独立窗口”放大。若手动关掉预览，可再次点击“相机预览”。预览不会启动遥操作。
5. 勾选工具栏“实时”后再运行，可按仿真速度观看；取消后可加速验收。停止会结束控制器，重跑请先 F8 重置。

## 复用标定数据

scene.yaml 的 robots[0].args.calibration_file 默认指向 ../hand_eye/results/panda_wrist_rgb.json。默认提供的是独立 Panda 标定场景实际生成并通过留出验证的数据。

流程为：加载并检查标定文件 → RGB/HSV识别 → 抓取 → 分类入框。不会重新采集标定图片，也不会在水果场景添加标定板。

要更新标定，运行“文件 → 手眼标定 Demo → Panda 手眼标定…”，通过后会自动更新结果文件。随后重载水果场景再运行。换机械臂、夹爪、相机安装或相机内参后，旧标定会因配置不匹配而被拒绝；请用对应标定场景生成新文件。

## 实现与输出

- scene.yaml、controller.py：软件内加载和编辑运行的入口。
- core.py：HSV、2.5D 反投影、抓取与结果检查；不执行标定。
- native.py：读取平台后端 RGB、编码器和接触力，发送识别叠加画面。
- physics.json、物理参数.md：质量、摩擦、力限制与公开资料依据。
- ../hand_eye：独立标定工具、场景、配置与结果。

软件输出目录为 demo/fruit_sorting/runs/in_app/，包含 hand_eye_used.json（本次实际使用的标定副本）、result.json、识别图片和物理审计。

RGB → HSV → 阈值分割 → 轮廓/中心/类别。黄香蕉 H=18–38，红苹果 H=0–12/170–179，紫葡萄 H=125–165。工作区和分拣框内的检测会显示类别，只有工作区中的有效目标用于规划；已放入框的水果仍可能显示识别框。

定位使用标定结果与已知台面/水果尺寸的 2.5D 反投影。水果真值仅用于最终落框核验，不用于抓取定位。公开通用物理参数与简化刚体模型不代表实物无损抓取验证。

## 独立入口

使用 64 位 Python 3.12 虚拟环境，在项目根目录按 [demo 快速运行](../README.md#快速运行)安装平台和视觉依赖。硬件及渲染要求统一见[主 README](../../README.md#配置建议)。

```bash
# 独立窗口
python -m demo.fruit_sorting
# 无 GUI 验证，仍需要离屏渲染 RGB 图像
python -m demo.fruit_sorting --headless --output demo/fruit_sorting/runs/latest
```

这些入口也直接读取已保存的标定文件。腕部相机使用 640×480 分辨率；修改该分辨率、内参或挂载后需重新标定，降低 GUI 主视口画质则不需要。
